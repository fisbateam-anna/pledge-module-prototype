# Сверка прототипа со списком работ

Источник: `Экспресс-оценка Залоги S__ 110626 выжимка для ИИ.xlsx`.
Дата проверки: 2026-06-17.

## Факт по Excel

В книге 2 листа: `Состав работ` и `Ограничение к оценке`. Excel-комментариев как отдельных примечаний нет; проверялась колонка `комментарии` на листе `Состав работ`.

Ключевые проверенные блоки:
- АРМ пользователя: роли, реестры задач/договоров/залогов, фильтры, таблицы, графики и связка графиков с таблицами.
- Работа с задачами: распределение, переназначение, статусы, стандартные действия, нормативные сроки.
- Карточки договора, залога и задачи.
- Создание задач вручную из карточки залога и из АРМ пользователя.
- Создание задач по конвейеру, расписанию и триггерам в демонстрационном режиме.
- Интеграции и журналы обменов.
- Мобильные сценарии сотрудника и клиента.
- Ограничения: АБС как мастер-система, страхование и кредитные показатели только отображаются, клиентская карточка не ведется.

## Найденное расхождение

Сценарий ручного создания задач был упрощен: форма создавала задачу только по одному заранее выбранному залогу и не отражала логику из комментария к строке `Создание задач вручную`:
- Вариант А: из карточки залога с автоматической привязкой текущего объекта.
- Вариант Б: из АРМ пользователя с ручным формированием пула объектов.
- Множественный выбор объектов из реестра.
- Добавление нового объекта залога, если его нет в реестре.
- Привязка документов к задаче или к конкретному объекту.
- Фоновый запуск внешних проверок при задачах осмотра, переоценки и мониторинга.

## Что исправлено

- Кнопка `Создать задачу` в реестре задач открывает сценарий из АРМ с пустым пулом объектов.
- Кнопка `Создать задачу` в карточке залога открывает сценарий из карточки и автоматически добавляет текущий залог в пул.
- Добавлен поиск и множественный выбор залогов из реестра.
- Добавлено создание нового объекта залога из формы задачи с включением в пул.
- Добавлена привязка документов к задаче в целом или к выбранному залогу.
- Добавлен расчет и отображение нормативного срока по типу/приоритету/источнику.
- Созданная задача хранит `collateralIds`, `objectPool`, `documents`, `normativeTerm`.
- В реестре задач отображается признак пула объектов.
- В карточке задачи отображается список объектов и документы.
- При создании задач на осмотр/переоценку/мониторинг имитируется фоновый запуск интеграций и запись в историю/аудит.

## Остаточные допущения прототипа

- Все операции выполняются во фронтенд-mock-слое без backend.
- Создание задач по расписанию, триггерам и конвейеру показано как демо-сценарии/источники/журналы, а не как реальный планировщик.
- Расчет нормативного срока сделан демонстрационно по 3 параметрам: тип задачи, приоритет, источник.
- Новый объект залога создается с минимальным набором обязательных mock-полей, достаточным для дальнейшего открытия карточки и участия в задаче.

- строка 18: `Внешние данные`;

Дополнительно проверены основные маршруты нового прототипа: реестр задач, создание задачи, реестр договоров, карточка договора, реестр залогов, карточка залога, отчеты руководителя, интеграции администратора, аудит администратора, мобильный сценарий сотрудника и клиента. Отдельный раздел `Импорт Excel` из АРМ удален: загрузка объектов из таблицы запускается кнопкой `Загрузить из таблицы` в реестре залогов. Пустых/битых экранов на проверке не выявлено.


## Дополнительная правка загрузки залогов от 2026-06-17

Факт: отдельный пункт меню `Импорт Excel` в АРМе не нужен.

Исправлено в новом прототипе:
- Пункт `Импорт Excel` удален из основной навигации и меню роли `Специалист`.
- В реестре залогов добавлена кнопка `Загрузить из таблицы`.
- Кнопка открывает модальное окно с выбором файла, шаблоном, предпросмотром строк и протоколом ошибок.
- Действие `Загрузить в реестр` имитирует загрузку: создает новый объект `COL-009`, обновляет `COL-003` и `COL-007`, ошибочные строки оставляет в протоколе.
- В журнал действий пишется источник `Реестр залогов`, а прямой старый маршрут `/app/import/collaterals` показывает реестр залогов, а не отдельный раздел.

Автопроверка: навигация специалиста содержит только `Задачи`, `Договоры`, `Залоги`; кнопка загрузки есть в реестре; модальное окно открывается; после применения строк в реестре появляется `COL-009`, источник `Таблица клиента`, счетчик объектов становится `9`.


## Дополнительная правка анализа рынка аналогов от 2026-06-17

Факт из строки 35 листа `Состав работ`: блок `Анализ рынка аналогичных объектов в регионе` должен быть не реестром аналогов, а сравнительной таблицей, где один столбец = один залог-аналог, а строки = характеристики, корректировки и итоговые расчеты.

Исправлено в новом прототипе:
- Обычная таблица `Источник / Объект / Цена / Корректировка / Итог` заменена на сравнительную матрицу.
- В таблице 3 фиксированных столбца аналогов и первый столбец `Характеристика`.
- Добавлены секции `1. Характеристики объекта`, `2. Корректировка цены, %`, `3. Автоматические итоговые расчеты`.
- Добавлены обязательные сквозные строки: наименование/модель, год выпуска/дата регистрации, дополнительные сведения, дата продажи/предложения, цена, источник/документ-основание.
- Динамические строки меняются по типу залога: для недвижимости выводятся район, площадь, этажность, комнаты, состояние; для автотранспорта — марка/модель, год, пробег, тип ТС, техническое состояние.
- Корректировки вводятся в процентах по каждому аналогу, итоговые строки рассчитаны в mock-слое.

Автопроверка задачи `TSK-2026-1098`: матрица есть, 4 колонки (`Характеристика` + 3 аналога), все три логические секции и итоговая рыночная стоимость отображаются.
