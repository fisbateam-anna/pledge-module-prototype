# Залоговый модуль S - frontend-прототип

## Запуск

```bash
cd "/home/user/BA_LandochkinaA/Залоговый модуль S/Прототип"
python3 -m http.server 5173
```

Открыть в браузере:

```text
http://127.0.0.1:5173/
```

Если порт занят, используйте соседний порт, например:

```bash
python3 -m http.server 5174
```

В текущей проверке прототип запущен на:

```text
http://127.0.0.1:5174/
```

## Что реализовано

- Самодостаточный frontend-only SPA без backend и внешних сервисов.
- Ролевая навигация и переключатель ролей.
- Реестры задач, договоров и залогов с фильтрами, сортировкой, KPI и интерактивными диаграммами.
- Карточка задачи с действиями: сохранить, отложить, вернуть, завершить, переназначить, передать в АБС.
- Карточка договора с участниками сделки, связанными залогами и показателями покрытия.
- Карточка залога с вкладками: общая информация, мониторинг, оценки, страхование, договоры и обременения, залогодатели, риски, внешние данные, документы, история.
- Создание задачи вручную с выбором типа, объекта, исполнителя, срока и документов.
- Имитация импорта Excel с протоколом корректных, обновляемых и ошибочных строк.
- Отчеты руководителя и печатные формы.
- Мобильные сценарии для выездного сотрудника и клиента.

## Роли

- Специалист залогового подразделения: задачи, договоры, залоги, импорт, создание задач, редактирование разрешенных полей.
- Руководитель подразделения: все задачи подразделения, переназначение, отчеты, аналитика.
- Выездной сотрудник Банка: только мобильные задачи осмотра и фотофиксация.
- Клиент: только активный дистанционный запрос Банка и фотофиксация.
- Администратор/методолог: контроль данных, риск-параметры и роли без отдельного пользовательского раздела логов.

## Имитированные интеграции

- АБС: ежедневный импорт сделок и обеспечений, передача статусов и результатов задач.
- Кредитный конвейер: создание задач, передача файлов, получение вердикта.
- Архив кредитной документации: получение документов по залогу.
- Monitoring/Collection: получение сигналов риска, статусов взыскания и реализации.
- Государственный залоговый реестр РУз, кадастр, СБДД/ГАИ: внешние проверки и обогащение данных.
- Avtoelon.uz и OLX.uz: поиск аналогов для анализа рынка.

## Технические ограничения

В текущей среде не установлены `node` и `npm`, поэтому прототип реализован без Vite/React-зависимостей. Код разложен по `src/data.js`, `src/app.js`, `src/styles.css` и может быть перенесен в React/Vite без изменения продуктовой структуры экранов.
